# 🌪️ Mistral AI Provider Guide & Examples

Mistral AI provides frontier models (`mistral-large-latest`, `codestral-latest`, `mistral-small-latest`) with European data compliance and fast inference.

---

## 🔑 How to Get and Set Up Your Mistral API Key

### 1. Obtain an API Key
1. Go to the **[Mistral Console](https://console.mistral.ai/)**.
2. Create an API key.

---

### 2. How to Set Your API Key

- **PowerShell**: `$env:MISTRAL_API_KEY="YourKeyHere..."`
- **Bash**: `export MISTRAL_API_KEY="YourKeyHere..."`
- **.env**: `MISTRAL_API_KEY=YourKeyHere...`
